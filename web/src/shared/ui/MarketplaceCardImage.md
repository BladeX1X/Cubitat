# MarketplaceCardImage

Comparte la carga de miniaturas entre Servicios y Materiales. Las cuadrículas de ambos catálogos y Favoritos deben usar este componente; un `<img>` directo omite sus prioridades y fallback. Optimiza URLs de Unsplash a 420 px/calidad 45. Las referencias privadas reciben el bucket validado por el catálogo y solo se firman al acercarse al viewport (margen de 400 px); las dos primeras tarjetas se firman de inmediato con prioridad alta. El detalle sigue firmando su galería completa al abrirse. Los fallos conservan el fallback accesible. No almacena URLs firmadas en la base ni expone objetos privados.
