# FeaturedHomeServicesSection

Pie reutilizable de recomendaciones para las fichas de marketplace. Consulta
perfiles de servicio publicados, comprueba `profile_featured` vigente mediante
la RPC pública de beneficios y muestra hasta tres resultados excluyendo el
perfil actual. Solo firma y carga la portada. Si no hay beneficios vigentes o
falla alguna consulta, no presenta una sección vacía ni bloquea la ficha.
