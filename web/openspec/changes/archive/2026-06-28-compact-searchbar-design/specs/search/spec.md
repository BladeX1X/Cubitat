# Delta for Search: Rediseño Compacto de Barra de Búsqueda

## MODIFIED Requirements

### Requirement: Filtrado Básico de Búsqueda
El sistema MUST mostrar la barra de búsqueda y el selector en un formato compacto premium (alto aproximado de 52px).

#### Scenario: Interfaz de búsqueda premium compacta
- GIVEN un usuario en la página principal
- THEN el campo de ubicación y el selector de tipo de propiedad MUST tener un alto de 52px
- AND el tamaño del texto descriptivo MUST ser de 15px
- AND las sugerencias de ubicación MUST renderizarse con un texto de 14px y márgenes compactos
