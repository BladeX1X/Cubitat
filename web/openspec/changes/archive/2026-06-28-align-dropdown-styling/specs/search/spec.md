# Delta for Search: Alineación de Estilo de Dropdown

## MODIFIED Requirements

### Requirement: Filtrado Básico de Búsqueda
El sistema MUST permitir a los usuarios buscar inmuebles y ver sugerencias estilizadas con consistencia visual con los componentes de UI.

#### Scenario: Visualización de sugerencias
- GIVEN un usuario introduciendo texto en el buscador
- THEN el sistema MUST mostrar sugerencias con bordes redondeados (10px) y sombra
- AND las sugerencias individuales MUST tener la misma tipografía y comportamiento hover que los menús desplegables del sistema
