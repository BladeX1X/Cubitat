# Delta for Search: Rediseño Sección Cuba Portal

## MODIFIED Requirements

### Requirement: Filtrado Básico de Búsqueda
El sistema MUST mostrar una sección centralizada en Cuba con accesos directos de búsqueda temáticos en la página de inicio.

#### Scenario: Visualización de accesos directos de Cuba
- GIVEN un usuario en la página principal
- THEN el sistema MUST mostrar el título de sección "El portal inmobiliario más grande de Cuba"
- AND el sistema MUST listar 8 accesos directos estructurados en un grid de 4 columnas en escritorio
- AND cada acceso directo MUST mostrar un botón interactivo "Ver propiedades →"
